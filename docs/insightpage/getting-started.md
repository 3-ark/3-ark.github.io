# InsightPage Assistant: Getting Started

InsightPage is a Personal Knowledge Management (PKM) browser extension with integrated AI assistance, designed to help turn web browsing, research, and note-taking into a seamless workflow.

---

## Core Pillars

1. **AI Chat Engine**: Flexible chat interface connecting directly to local (Ollama, LM Studio) or cloud AI models (OpenAI, Gemini, Groq, OpenRouter).
2. **Floating Assistant**: In-context webpage AI actions and summary overlay window.
3. **Note Viewer & Vault**: Standard Markdown file sync using local file access APIs (`.md` files).
4. **Context & Web Clipper**: Highlight text and clip web content directly into markdown notes.
