# InsightPage Assistant: Key Features

## 1. Hybrid RAG Search
InsightPage combines:
* **BM25 Keyword Search** for exact word matching.
* **Semantic Embeddings Search** for concept matching.
* **MMR Reranking** for relevance optimization.

## 2. Floating Action Assistant
* Drag-and-drop floating action button (FAB).
* Automatic page summary and Q&A.
* One-click transfer to side panel.

## 3. Local Markdown Vault Integration
* Direct `.md` file reading and writing via Web File System Access API.
* Deep Wikilinks support (`[[Note Title]]`).
* Note mentions (`@[Note Title]`) for contextual Q&A.
